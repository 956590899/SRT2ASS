## 快速开始

### 主程序

- **Z.py** - SRT转ASS一键处理字幕打包程序（主程序）

### 效果配置

修改 `Z.py` 文件开头的配置参数：

```python
REAL_KARAOKE_EFFECT = 0  # 真实卡拉OK效果设置
```

| 值 | 效果说明 |
|---|---------|
| 0 | 默认效果 |
| 1 | 真实卡拉OK式样 |
| 2 | 提词器式样 |
| -1 | 全选（同时处理所有效果） |

> **建议**: 转换效果推荐使用默认效果，因为自动打轴准确率只能保证80%（歌词语速均匀时准确率更高），方便后续修改。当卡拉OK准确率确认可用后，可通过 Z1.py 进行式样转换。

## Z1.py 二次加工配置

打开 `SRT/Z1.py` 可配置以下参数：

```python
STEREO_TO_5_1 = 0    # 0或1（开关5.1音频转换）
SUBTITLE_MODE = 1    # 0、1或2 字幕效果转换
```

### SUBTITLE_MODE 参数说明

| 值 | 效果说明 |
|---|---------|
| 0 | 关闭，保持原始字幕 |
| 1 | 真实卡拉OK效果 |
| 2 | 提词器效果 |
| -1 | 全选（同时处理所有效果） |

## 功能特性

### 核心功能

- SRT/VTT/LRC/SSA/ASS 字幕格式转换
- 卡拉OK效果自动打轴
- 人声分离（Demucs引擎）
- MKV视频打包
- 多字幕处理支持
- 自定义字体支持

### 音频处理

- 立体声转5.1声道
- 人声分离提取

### 字幕效果

- 默认卡拉OK效果
- 真实卡拉OK式样
- 提词器滚动效果

## 使用说明

1. 运行 `GUI.py` 启动图形界面
2. 拖拽字幕文件或视频文件到窗口
3. 选择输出效果模式
4. 点击开始处理

---

## 注意事项

- 自动打轴准确率约80%，建议使用默认效果方便修改
- 确认卡拉OK时间轴准确后再进行式样转换
- GPU加速需要NVIDIA显卡和CUDA支持
