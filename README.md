# SRT2ASS 字幕制作工具

## 📋 项目概述

**SRT2ASS** 是一款功能全面的视频字幕与音频处理工具集，提供从字幕格式转换、卡拉OK效果制作、人声分离到MKV视频打包的一站式解决方案。

- **版本**: 1.8.0 Summerキッス
- **开发语言**: Python
- **UI框架**: Tkinter
- **支持平台**: Windows

---

## ✨ 核心功能

### 字幕处理
- **多格式字幕转换** - 支持 SRT、VTT、LRC、SSA、ASS 等字幕格式
- **自动卡拉OK效果** - 三种卡拉OK效果供选择
- **多字幕支持** - 同时处理多语言字幕
- **自定义字体** - 内置多种精美字体，支持自定义字体替换

### 音频处理
- **人声分离** - 基于 Demucs 引擎，智能分离人声与背景音乐
- **立体声转 5.1 声道** - 沉浸式音频体验
- **音频文件批量重命名** - 基于音乐标签智能重命名

### 视频处理
- **MKV 视频打包** - 使用 MKVToolNix 进行专业视频封装
- **媒体格式转换** - 支持多种视频格式转换
- **歌词适配** - 自动匹配与处理歌词

## 🚀 快速开始

### 方法一：GUI 界面（推荐）

运行 `SRT/GUI.py` 启动图形化界面：

```bash
cd SRT2ASS/SRT
python GUI.py
```

### 方法二：命令行模式

直接运行各模块脚本进行处理：

```bash
# SRT转ASS一键处理字幕打包
python Z.py

# 字幕式样替换与音频处理
python Z1.py
```

## ⚙️ 配置说明

### Z.py 配置（主程序）

修改 `SRT/Z.py` 开头的配置参数：

```python
# 真实卡拉OK效果设置：
# 0: 默认效果
# 1: 真实卡拉OK效果
# 2: 提词器效果
# -1: 全选，同时处理所有效果
REAL_KARAOKE_EFFECT = -1
```

### Z1.py 配置（二次加工）

修改 `SRT/Z1.py` 中的配置参数：

```python
# 立体声转5.1声道转换开关
STEREO_TO_5_1 = 0  # 0或1

# 字幕处理模式开关
SUBTITLE_MODE = -1  # 0、1、2或-1（全选）

# 字体替换开关
ENABLE_FONT_REPLACEMENT = 1  # 0或1

# 字体设置选项
FONT_SETTING = 2  # 0、1或2
```

#### 详细参数说明

| 参数 | 值 | 说明 |
|------|-----|------|
| `SUBTITLE_MODE` | 0 | 关闭，保持原始字幕 |
| | 1 | 真实卡拉OK效果 |
| | 2 | 提词器效果 |
| | -1 | 全选，同时处理所有效果 |
| `FONT_SETTING` | 0 | 默认（不启用修改） |
| | 1 | 系统字体 |
| | 2 | 自定义字体 |

## 📖 使用提示

1. **自动打轴准确率**约为 80%，建议先使用默认效果方便后续修改
2. 确认卡拉OK时间轴准确后，再进行式样转换
3. 使用 GUI 界面可获得最佳体验，支持拖拽文件操作
4. 字体配置可在 GUI 的「设置选项」中进行
